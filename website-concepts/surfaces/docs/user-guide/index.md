# User guide

Learn the scientific model and analysis workflow shared by every EasyDiffraction interface. A project, its structures and experiments, and its fitting choices have the same meaning in the application, Python and the command line.

## Foundations

| Topic | What it explains |
| --- | --- |
| [Introduction](introduction.md) | What EasyDiffraction does and how this documentation is organised |
| [Concept](concepts.md) | Acquisition, reduction and model-dependent analysis |
| [Data formats](data-formats.md) | Edi projects, structural CIFs, measured patterns and reports |
| [Parameters](parameters.md) | Values, units, free and fixed quantities, uncertainties and constraints |
| [Glossary](glossary.md) | Shared scientific terms and experiment labels |

## Analysis workflow

Follow the model from inputs to a result you can inspect and share:

**[Project](analysis-workflow/project.md) → [Structure](analysis-workflow/structure.md) → [Experiment](analysis-workflow/experiment.md) → [Analysis](analysis-workflow/analysis.md) → [Report](analysis-workflow/report.md)**

The [workflow overview](analysis-workflow/index.md) explains how these stages connect. Each stage describes the scientific choices and links to the relevant interface procedures.

## Plan and assess

Choose [fitting modes](fitting-modes.md), assess [fit quality](fit-quality.md), and select an [example project](examples.md) for the measurement or task you want to explore.

## Carry out the steps

Use [Application](../application/index.md) for buttons and visual controls, [Python](../python/index.md) for objects and method calls, and [Command Line](../cli/index.md) for terminal commands and options. [Get started](../get-started/index.md) helps you choose an interface and complete a first run.
