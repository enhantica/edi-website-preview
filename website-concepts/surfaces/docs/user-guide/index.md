# User guide

EasyDiffraction keeps your structures, experiments, analysis settings and results together in one project. This guide explains the common model and workflow used by every interface.

## Choose an interface

Start in the interface you want to use. Each section has its own setup and first refinement, followed by the same analysis stages.

| How you want to work | Start here | First refinement |
| --- | --- | --- |
| Visually, in a browser or on your desktop | [Application](../application/index.md) | [Follow an example](../application/first-refinement.md) |
| In a Python script or notebook | [Python](../python/index.md) | [Run an example](../python/examples.md) |
| From a terminal or shell script | [Command Line](../cli/index.md) | [Run an example](../cli/examples.md) |

## Understand the analysis

The [introduction](introduction.md) and [concept](concepts.md) explain what an analysis contains. Use [data formats](data-formats.md), [parameters](parameters.md) and the [glossary](glossary.md) as you prepare your own work.

## Follow the workflow

**[Project](analysis-workflow/project.md) → [Structure](analysis-workflow/structure.md) → [Experiment](analysis-workflow/experiment.md) → [Analysis](analysis-workflow/analysis.md) → [Report](analysis-workflow/report.md)**

The [workflow overview](analysis-workflow/index.md) connects these stages. Choose the [fitting mode](fitting-modes.md) for your observations and use [fit quality](fit-quality.md) to assess the result. [Example projects](examples.md) provide complete starting models and measurements.

## Understand the physics

[Physics](../physics/index.md) explains diffraction, scattering, peak profiles, refinement equations and conventions behind the calculations. The interface sections explain the corresponding controls, calls and commands.
