# Example projects in the application

Open the [web app](https://enhantica.github.io/edi/webapp/), go to **Project**, and expand **Examples**. Choose a measured-data example for [your first refinement](first-refinement.md), or choose a simulation to inspect a calculated pattern without fitting.

Examples open as working copies. Use **Save project as…** to keep your changes in your own project.

Choose a scientific case in the shared [example catalogue](../user-guide/examples.md).
